Para ejecutar seguir las siguientes instrucciones: 
- En el CMakeLists setear la variable DILIGENT_ROOT a la ruta donde se encuentra Diligent Engine instalado localmente
- Luego, copiar todos los dlls dentro de build/Debug del repositorio a un lugar seguro
- Borrar la carpeta de build
- Hacer cmake .. en la carpeta raíz del proyecto
- Abrir el .sln y hacer build del proyecto o directamente abrir el .exe generado anteriormente
